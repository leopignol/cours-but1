# Oral Presentation
## Subject: Debian
https://www.debian.org/

### Notes

Debian is one of the first GNU/Linux distributions, realesed in 1996

It is widely known as the most stable distribution available, used in more than 30% of all servers in the world

Debian has been derived into thousands of distributions, the main ones being:

- Ubuntu, derived to:
  - Linux mint
  - Zorin OS
- Kali Linux
- Knoppix
- Raspbian OS
- Tails OS
- GParted

Compared to raw GNU/Linux, Debian adds:

- Prebuilt kernel
- Prebuilt drivers
- Netinstall
- Partition manager
- APT package manager
- Desktop environment choice in installer
